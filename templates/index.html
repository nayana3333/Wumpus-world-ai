    Click any square on the board to see what the CNF knowledge base can prove about it, and the resolution steps that get there.

    How it works

    Goal

    You start bottom-left in a dark N×N cave. Find the gold, carry it back to the start square, climb out. You only ever see the square you are standing in.

    Percepts

    • Stench - Wumpus in an adjacent square
    • Breeze - pit in an adjacent square
    • Glitter - gold in this square
    • Bump - you walked into a wall
    • Scream - your arrow hit the Wumpus

    Actions

    • Move to an adjacent square
    • Grab the gold when it glitters
    • Shoot your one arrow along a row or column
    • Climb out, only from the start square

    Score

    • +1000 climb out holding the gold
    • -1000 die
    • -10 fire the arrow
    • -1 every action

    The agents

    Logic

    Percepts go into a CNF knowledge base. DPLL answers "is a pit here entailed?" by testing whether the KB plus the opposite is unsatisfiable. The Proof tab shows the resolution steps.

    Because there is exactly one Wumpus, "stench at X iff Wumpus adjacent to X" is a biconditional, so a few percepts often pin it to one square.

    Probability

    When nothing is provably safe, the agent counts models: every pit layout on the frontier consistent with every breeze, weighted by the prior. That gives P(pit) per square, and it moves to the lowest one under its risk threshold.

    Q-learning

    Told none of the above. It sees a state key and a reward and has to work out that breezes are bad. Use the Train RL button to watch the learning curve.

    Reflex / random

    Baselines. The reflex agent applies a single one-step safety rule and has no plan, so it frequently gets stuck walking back and forth.

    Benchmark

    Every agent plays the same sequence of caves, so the difference is the agent rather than luck.

    4x4 with 3 pits is the textbook setup. Raise the pit count to see the logic agent refuse to gamble while the probabilistic one keeps going.

    Train the Q-learning agent

    Trains a fresh Q-table from zero on random caves and plots average score per block of episodes. The bundled agent was trained the same way, just for longer.
